# Lasting Power of Attorney Front End

This folder now contains the FastAPI rewrite of the lasting power of attorney front-end. It exposes the public HTML routes rendered with Jinja2 templates and serves legacy static assets from `public/assets`.

## Getting started

1. Ensure Python 3.13 is installed (`asdf install` will read `.tool-versions`).
2. Install dependencies into a local virtual environment:

   ```bash
   uv pip install -e .[dev]
   ```

3. Run the development server:

   ```bash
   uv run uvicorn app.main:app --reload
   ```

   The service listens on http://127.0.0.1:8000 by default.

## Running with Docker Compose

To run the front end together with the service API and Postgres, execute from the repository root:

```bash
docker compose -f docker-compose.fastapi.yml up --build
```

The front end is available at http://localhost:8000. Use the "Create an account" button on the start page to register a new user; the flow will automatically activate the account and sign you in.

## Tests

Unit tests use pytest and httpx. Execute them via:

```bash
uv run pytest
```

## Static content

- Markdown guidance content is stored in `content/guidance`. Filenames are converted into slugs automatically.
- Compiled GOV.UK static assets live in `public/assets` and are mounted under `/static` by FastAPI.

## Project layout

```
app/
  config.py       # Pydantic settings for runtime configuration
  main.py         # FastAPI entry point
  routes/         # Route definitions for health checks and general pages
  services/       # Supporting services (e.g. Markdown guidance loader)
  templates/      # Jinja2 templates for HTML rendering
content/          # Source guidance markdown
public/assets/    # Legacy static assets served directly
```

## Extending the service

- Add new public pages by creating a template under `app/templates/general` and wiring an endpoint in `app/routes/general.py`.
- For new Markdown content, drop a file into `content/guidance`; the slug is generated by filename.
- Re-run `uv run pytest` after changes to verify behaviour.
